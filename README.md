# chess-forces

Can a structural, "forces on a fixed field" view of chess predict endgame outcomes more compactly than lookup tables at the same compute budget? Every candidate is scored against exact endgame truth: program size plus the cost of listing its mistakes, plotted against operations per position.

Status: Phase 1 plus a first search run (docs/02-agent-loop.md). The KPK truth table is generated by own code and verified against Syzygy, position by position. The DSL, its interpreter, the scorer, the baselines and a hand-written rule set exist; results are in [reports/kpk.md](reports/kpk.md). Design: [docs/01-dsl-concept.md](docs/01-dsl-concept.md).

## Setup

    uv sync            # Python 3.13 venv in .venv
    uv run chess-forces kpk   # build the KPK table, check its hash
    uv run chess-forces evolve --run r1 --usd 2   # search loop; needs CHESS_FORCES_API_KEY and spends money
    uv run chess-forces report   # baselines, table and plot (about a minute)
    uv run chess-forces score programs/square.dsl   # size, exceptions, operations
    uv run chess-forces spec   # the language, generated from the code
    uv run pytest             # tests; the Syzygy check is skipped if the tables are missing

Syzygy 3-4-5 tables are expected in `../syzygy`, or wherever `SYZYGY_PATH` points.

## API budget

Phase 2 scripts call the API only through `chess_forces.budget`. A call is reserved at its worst-case price first; if it would pass the daily limit (20 USD by default) or the account total, nothing is sent and the script exits with code 75. Finished work is stored, so rerunning the same command continues where it stopped.

    uv run chess-forces budget init --total <USD>   # once, per machine
    uv run chess-forces budget status
    uv run chess-forces budget confirm <USD>        # more for today; asks in a terminal
    uv run chess-forces budget topup <USD>          # after adding money in the Console

A new day starts with a fresh daily limit. The ledger only sees calls made through it, so use an API key that nothing else uses, with a spend limit set in the Console.

The key is read from `CHESS_FORCES_API_KEY` only.
